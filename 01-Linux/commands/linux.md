### 📝 ملحوظة

الأمر `file` في Linux بيستخدم لمعرفة **نوع محتوى الملف**، مش مجرد امتداد الملف.

وده مفيد جدًا لما تكون عندك ملفات بأسماء غريبة أو من غير Extensions، وعايز تعرف أي ملف فيهم عبارة عن **text file**.

مثال:

</div>

```bash
file ./*
```

### 📝 ملحوظة

الأمر `find` بيستخدم للبحث عن الملفات بناءً على خصائص معينة.

</div>

```bash
find . -type f -size 1033c ! -executable
```
